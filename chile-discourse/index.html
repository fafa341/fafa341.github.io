┌──────────────────────────────────────────────────────────────────┐ │ NLP PIPELINE │ └──────────────────────────────────────────────────────────────────┘ Raw HTML web.archive.org · La Tercera + Biobío · 60,348 articles │ Jan 2012 → Dec 2024 ▼ Clean Remove boilerplate · decode \\uXXXX escapes │ normalize unicode · strip copyright noise ▼ NLP Stanford Stanza · tokenization · lemmatization │ POS tagging · Spanish named-entity recognition ▼ Feature Matrix TF-IDF bag-of-words · 10,000-term vocabulary │ Sparse document-term matrix (60K × 10K) ▼ LDA K = 10 topics · sklearn · online learning │ Document-topic matrix (60K × 10) │ Topic-word matrix (10 × 10K) ▼ Sentiment BETO (Spanish BERT) · positive / negative / neutral │ Per-article labels + probability scores ▼ Aggregation Proportion-weighted monthly averages per topic │ 156 monthly snapshots · Banco Central macro overlay ▼ Visualization Vanilla JS · D3 v7 · Static JSON · GitHub Pages

LDA Topic Modeling

Latent Dirichlet Allocation discovers latent themes from word co-occurrence. Each article is a soft mix of all 10 topics, enabling temporal analysis.

NLP: Stanford Stanza

Spanish-language NLP pipeline for tokenization, lemmatization, POS tagging, and named-entity recognition — enabling clean, linguistically-aware text features.

Corpus: La Tercera + Biobío

Two leading Chilean outlets — La Tercera (national) and Biobío (digital-native) — archived via the Wayback Machine across four presidential terms.

Sentiment: BETO

Spanish-language BERT model, fine-tuned on Chilean news. Per-article sentiment aggregated to monthly resolution by dominant topic.

Macro Correlation

Monthly IMACEC and unemployment from Chile's Banco Central, overlaid to test whether discourse shifts lead macroeconomic conditions.
